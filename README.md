# Hand Gesture Controller

A Python-based desktop application that allows users to control basic computer functions using hand gestures detected through a webcam.

## Features

- Real-time hand detection
- Webcam-based gesture recognition
- Mouse movement
- Left click
- Right click
- Double click
- Scroll control
- Windows volume control
- Media control
- Modern CustomTkinter GUI
- Start and Stop controller
- Gesture cooldown to reduce repeated actions

## Technologies Used

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- CustomTkinter
- Pycaw
- Pillow
- JSON
